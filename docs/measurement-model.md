# Measurement Model

OpenAIMeter records use schema version `1.0` and store source, attribution, model identity, usage, performance, cost, outcome, correlation, and metadata fields. Quantitative values must be interpreted with provenance and calculation method fields.

Required fields are `schema_version`, `record_id`, `record_type`, `start_time`, `end_time`, `model`, `usage`, `performance`, and `cost`.
